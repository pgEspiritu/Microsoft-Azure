## 1. If you plan to host a web application in the Azure platform as a service solution of Azure Web Apps, then the platform will have the ability to scale automatically?

- Yes.
- No.

**Answer:** Yes.

**Explanation:** Azure Web Apps (Azure App Service) supports automatic scaling. You can configure scaling rules so that the application can automatically add or remove instances based on demand, helping maintain performance while optimizing resource usage.

## 2. You decide to create 2 Virtual machines. Each virtual machine is of the size D2s v3. Would these machines always generate the same monthly cost?

- Yes.
- No.

**Answer:** No.

**Explanation:** The size of the virtual machine is only one factor that determines its cost. The monthly cost can vary depending on factors such as the region where the VM is deployed, operating system licensing, disk/storage configuration, usage hours, and other attached resources. Therefore, two D2s v3 virtual machines will not necessarily have the same monthly cost.

## 8. Your company needs to deploy an application to virtual machines hosted in Azure. The solution must ensure an SLA of 99.99%. What is the minimum number of virtual machines and availability zones that you need to recommend for the deployment?

- One virtual machine and One availability zone.
- Two virtual machines and availability zone.
- One virtual machine and Two availability zones.
- Two virtual machines and Two availability zones.

**Answer:** Two virtual machines and Two availability zones.

**Explanation:** To achieve a 99.99% SLA for virtual machines, the application should be deployed across at least **two virtual machines in two separate availability zones**. This provides redundancy and protects the application from a failure affecting a single availability zone.

**Why the others are incorrect:**
- **One virtual machine and One availability zone** — Does not provide sufficient redundancy if the VM or zone becomes unavailable.
- **Two virtual machines and availability zone** — If both VMs are in the same availability zone, a zone-level failure can affect both.
- **One virtual machine and Two availability zones** — A single VM cannot provide redundancy across two zones.
- **Two virtual machines and Two availability zones** — Correct. The VMs can be distributed across separate availability zones to provide higher availability and meet the 99.99% SLA requirement.

## 10. A company is planning on hosting an application on an Azure Virtual Machine. It needs to be ensured that the application hosted on the virtual machine is accessible from the Internet over HTTPS. You decide to implement a DDoS protection plan. Would this satisfy the requirement?

- Yes.
- No.

**Answer:** No.

**Explanation:** Azure DDoS Protection is designed to protect Azure resources from distributed denial-of-service (DDoS) attacks. It does **not** make an application accessible over HTTPS. To satisfy the requirement, the application must have HTTPS configured, typically by using a web server with an SSL/TLS certificate and allowing HTTPS traffic through the appropriate network security rules.

**Why the answer is No:**
- **DDoS Protection** — Protects against DDoS attacks but does not provide HTTPS connectivity.
- **HTTPS access** — Requires the application/web server to be configured for HTTPS and TCP port 443 to be accessible.

---

## 11. A company is planning on hosting an application on an Azure Virtual Machine. It needs to be ensured that the application hosted on the virtual machine is accessible from the Internet over HTTPS. You decide to implement an Azure Traffic Manager profile. Would this satisfy the requirement?

- Yes.
- No.

**Answer:** No.

**Explanation:** Azure Traffic Manager is a DNS-based traffic load balancer that distributes user traffic across different Azure endpoints based on routing methods such as performance, priority, geographic location, or weighted distribution. It does not itself configure an Azure Virtual Machine application to be accessible over HTTPS.

To satisfy the requirement, the application on the VM must be configured to support HTTPS, including an SSL/TLS certificate and appropriate network access to HTTPS (TCP port 443).

**Why the answer is No:**
- **Azure Traffic Manager** — Helps route users to appropriate endpoints but does not enable HTTPS on the application.
- **HTTPS** — Requires the application/web server to be configured for secure HTTP using SSL/TLS.

## 17. If you plan to host a web application in the Azure platform as a service solution of Azure Web Apps, then you will have complete control over the underlying operating system.

- Yes.
- No.

**Answer:** No.

**Explanation:** Azure Web Apps (Azure App Service) is a **Platform as a Service (PaaS)** offering. Microsoft manages the underlying operating system, servers, and infrastructure. You can manage your application and its configuration, but you do not have complete control over the underlying operating system.

**Why the answer is No:**
- **Azure Web Apps** — Microsoft manages the underlying infrastructure and operating system.
- **Virtual Machines (IaaS)** — Give you much greater control over the operating system because you are responsible for managing the VM's OS.

## 18. You decide to create a virtual machine which is of the size D2s_v3. If you plan to stop the virtual machine, will you incur any costs for the storage associated with the virtual machine.

- Yes.
- No.

**Answer:** Yes.

**Explanation:** Stopping (deallocating) an Azure virtual machine stops the compute charges, but the disks and other storage resources attached to the VM continue to exist and incur storage charges. Therefore, you will still pay for the storage associated with the virtual machine even when the VM is stopped.

**Why the answer is Yes:**
- **Compute charges** — Generally stop when the VM is stopped and deallocated.
- **Storage charges** — Continue because the managed disks and other storage resources remain provisioned.

## 19. Your company is planning on using Azure for hosting Infrastructure level resources such as Azure Virtual Machines. When planning for the costing aspect for these resources, is there a flexibility offered when it comes to Capital and Operational Expenditure.

- Yes.
- No.

**Answer:** Yes.

**Explanation:** Azure provides flexibility between **Capital Expenditure (CapEx)** and **Operational Expenditure (OpEx)**. Instead of making a large upfront investment in physical hardware and data centers (CapEx), organizations can use Azure resources and pay for them based on usage (OpEx). This allows companies to scale resources and costs according to their needs.

**Why the answer is Yes:**
- **Capital Expenditure (CapEx)** — Involves upfront spending on physical infrastructure such as servers, storage, and networking equipment.
- **Operational Expenditure (OpEx)** — Involves ongoing costs based on the consumption of cloud services.
- **Azure** — Primarily follows a consumption-based OpEx model, reducing the need for large upfront infrastructure investments.

## 20. You are looking at using a Software as a Service in Azure. Which of the following would you be responsible for?

- High availability of the solution.
- Configuration of the solution.
- Installing the solution.
- Scalability of the solution.

**Answer:** Configuration of the solution.

**Explanation:** In a **Software as a Service (SaaS)** model, the cloud provider manages the underlying infrastructure, operating system, application installation, availability, and scalability. The customer is primarily responsible for configuring and using the application according to their business requirements.

**Why the others are incorrect:**
- **High availability of the solution** — Generally managed by the cloud service provider.
- **Installing the solution** — The SaaS provider manages the application installation and infrastructure.
- **Scalability of the solution** — Generally managed by the cloud service provider.
- **Configuration of the solution** — The customer is responsible for configuring the SaaS application to meet their needs.
