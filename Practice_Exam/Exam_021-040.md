## 21. A company is planning on migrating all of their on-premises servers to Azure. Their business continuity department has advised that they need to ensure that servers hosted in Azure are available even if an Azure Data Center were to go down. Which of the following is a concept that would be involved in the design stage for this requirement.

- Scalability.
- Fault Tolerance.
- Low Latency.
- Elasticity.

**Answer:** Fault Tolerance.

**Explanation:** **Fault tolerance** is the ability of a system to continue operating even when one or more components fail. To protect against an Azure data center failure, resources can be distributed across separate availability zones or regions, depending on the required level of resilience.

**Why the others are incorrect:**
- **Scalability** — The ability to increase or decrease resources to handle changing workloads.
- **Low Latency** — Refers to minimizing the time required for data or requests to travel between systems.
- **Elasticity** — The ability to automatically provision or release resources in response to changes in demand.

- **They would need to pay for the number of connections to the web site.** — Azure does not generally charge simply based on the number of users or connections to a website; costs depend on the specific services and resources used.

## 23. An administrator needs to run a script written in PowerShell. This script is going to create a virtual machine in Azure. Would the script run on a computer that runs Linux and has the Azure CLI tools installed?

- Yes.
- No.

**Answer:** No.

**Explanation:** The Azure CLI and PowerShell are different command-line tools. Having the **Azure CLI** installed on a Linux computer does not mean that a PowerShell script can run automatically. A PowerShell script requires **PowerShell** (PowerShell 7 or later) to be installed and available on the system.

However, PowerShell is cross-platform and can run on Linux when PowerShell itself is installed.

**Why the answer is No:**
- **Azure CLI** — Used to execute Azure CLI commands such as `az vm create`.
- **PowerShell** — Required to execute PowerShell scripts and Azure PowerShell commands.
- **Linux** — Can run PowerShell, but PowerShell must be installed separately; having only Azure CLI installed is not sufficient.

## 33. A team is planning on deploying Azure Virtual Machines to a resource group named demogroup. The group has been created in the US Central region. Do the virtual machines deployed to the resource group also need to be deployed to the US Central region only?

- Yes.
- No.

**Answer:** No.

**Explanation:** An Azure **resource group is a logical container** for managing related resources. The resources within a resource group can be located in **different Azure regions**. Therefore, creating `demogroup` in the US Central region does not require all virtual machines in that resource group to be deployed in US Central.

The resource group's location is primarily used to store the group's metadata and does not determine the physical location of the resources it contains.

**Why the answer is No:**
- **Resource group location** — Determines where the resource group's metadata is stored.
- **Resource location** — Each Azure resource, such as a virtual machine, has its own location that can be selected independently, subject to the service's availability and regional restrictions.

## 34. A team is planning on assigning tags to a resource group. Would the tag be inherited by resources in the resource group?

- Yes.
- No.

**Answer:** No.

**Explanation:** Tags assigned to an Azure **resource group are not automatically inherited by the resources** contained within that resource group. Tags are applied independently to resources and resource groups.

If you want tags to be automatically applied to resources, you can use **Azure Policy** to enforce or inherit tags based on the resource group's tags.

**Why the answer is No:**
- **Resource group tags** — Apply only to the resource group itself.
- **Resource tags** — Must be assigned separately unless an Azure Policy is used to automatically apply or inherit tags.

## 35. A set of IAM permissions have been assigned to a resource group. Would the resources in the resource group automatically inherit the IAM permissions assigned to the resource group?

- Yes.
- No.

**Answer:** Yes.

**Explanation:** Azure role-based access control (Azure RBAC) permissions assigned at the **resource group scope are inherited by the resources** within that resource group. This allows administrators to grant users or groups access to multiple resources at once without assigning permissions individually to each resource.

**Why the answer is Yes:**
- **Resource group scope** — Permissions assigned at this scope apply to resources contained within the resource group.
- **Inheritance** — Azure RBAC assignments are inherited by child resources unless access is explicitly restricted or otherwise affected by the applicable role and scope.
