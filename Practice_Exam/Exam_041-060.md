## 41. Your company has just setup an Azure account and Microsoft Entra ID. - Microsoft Entra Connect.
- Microsoft Entra ID Protection.
- Microsoft Entra Privileged Identity Management.
- Microsoft Defender for Identity.

**Answer:** Microsoft Entra ID Protection.

**Explanation:** Microsoft Entra ID Protection helps detect and respond to identity-based risks. It can identify risky sign-ins, including sign-ins originating from **anonymous IP addresses**, such as Tor exit nodes. **Why the others are incorrect:**

- **Microsoft Entra Privileged Identity Management (PIM)** — Used to manage, control, and monitor access to privileged roles.
- **Microsoft Defender for Identity** — Monitors on-premises Active Directory signals to detect identity-based threats and suspicious activities.

## 42. A company is planning on creating several virtual machines that will be used to host web and database servers. You need to limit the type of connections from the web and database servers. Which of the following can be used to fulfil this requirement?

- Network Security Groups.
- Microsoft Entra ID Protection.
- Azure VPN.
- Azure Route tables.

**Answer:** Network Security Groups.

**Explanation:** **Network Security Groups (NSGs)** are used to control inbound and outbound network traffic to and from Azure resources. NSGs contain security rules that can allow or deny traffic based on factors such as source and destination IP addresses, ports, and protocols.

For example, you can configure an NSG to allow HTTP/HTTPS traffic to a web server while restricting database server access to only the required ports and sources.

**Why the others are incorrect:**
- **Microsoft Entra ID Protection** — Used to detect and respond to identity-related risks.
- **Azure VPN** — Provides secure connectivity between networks or clients and Azure; it is not primarily used to filter individual VM connections.
- **Azure Route tables** — Define how network traffic is routed between subnets and network interfaces but do not provide traffic filtering or allow/deny security rules.
