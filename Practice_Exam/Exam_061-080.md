## 65. You need to deploy several virtual machines to Azure. You need to ensure that you can assign permissions to the virtual machines simultaneously. Which of the following can be implemented to fulfil this requirement?

- Deploy all the virtual machines to the same region.
- Deploy all the virtual machines to the same resource group.
- Deploy all the virtual machines to the same availability zone.
- Deploy all the virtual machines to the same scale.

**Answer:** Deploy all the virtual machines to the same resource group.

**Explanation:** Azure role-based access control (**Azure RBAC**) allows permissions to be assigned at the **resource group scope**. When you assign a role to a user or group at the resource group level, the permissions are inherited by the resources within that resource group, including virtual machines.

Therefore, placing all the virtual machines in the **same resource group** allows you to assign permissions to them simultaneously.

**Why the others are incorrect:**
- **Same region** — Determines the physical Azure location but does not provide a common scope for assigning permissions.
- **Same availability zone** — Provides protection against datacenter-level failures within a region but does not group resources for access control.
- **Same scale** — VM scale is related to VM sizing or scaling and does not provide an RBAC permission scope.

**Exam tip:** For assigning permissions to multiple Azure resources at once, remember **Resource Group → RBAC inheritance**.

**Answer:** The Azure platform is a shared platform wherein multiple companies can use a portion of the resources on the platform.

**Explanation:** Azure is a **public cloud platform** based on a shared infrastructure model. Multiple customers and organizations use Azure's underlying infrastructure, while their resources and data remain logically isolated and protected through security and access-control mechanisms.

This shared model provides benefits such as **economies of scale, flexible resource allocation, scalability, and reduced infrastructure costs** compared with maintaining dedicated on-premises infrastructure.

**Why the others are incorrect:**

- **Private cloud** — Incorrect. Azure is primarily a public cloud platform, although Microsoft also offers dedicated and hybrid solutions.
- **Ecommerce platform** — Incorrect. Azure is a cloud computing platform, not an e-commerce marketplace for buying and selling resources.

**Exam tip:** Azure is a **public cloud** with a **shared infrastructure** model, where multiple customers securely use cloud resources.

- **A private cloud** — Requires the organization to maintain dedicated infrastructure, which can increase both capital and operational costs.
- **A hybrid cloud** — Uses existing on-premises resources together with public cloud resources, providing flexibility while avoiding the need to expand physical infrastructure.

## 72. You have 1,000 virtual machines hosted on the Hyper-V hosts in a data center. You plan to migrate all the virtual machines to an Azure pay-as-you-go subscription. You need to identify which expenditure model to use for the planned Azure solution. Which expenditure model should you identify?

- Operational.
- Elastic.
- Capital.
- Scalable.

**Answer:** Operational.

**Explanation:** A **pay-as-you-go Azure subscription** follows an **Operational Expenditure (OpEx)** model. Instead of making a large upfront investment in physical servers and data center infrastructure, the organization pays for Azure resources based on their usage.

**Why the answer is Operational:**
- **Operational Expenditure (OpEx)** — Ongoing costs based on the consumption of cloud services. This is the typical expenditure model for pay-as-you-go Azure resources.
- **Capital Expenditure (CapEx)** — Involves upfront investment in physical assets such as servers, storage, networking equipment, and data centers.
- **Elastic** — Describes the ability to dynamically scale resources based on demand; it is not an expenditure model.
- **Scalable** — Describes the ability to increase or decrease resource capacity; it is not an expenditure model.

**Exam tip:** Remember:

**On-premises hardware → CapEx**

**Pay-as-you-go cloud services → OpEx**

## 80. You need to identify the type of failure for which an Azure Availability Zone can be used to protect access to Azure services. What should you identify?

**Why the others are incorrect:**

**Exam tip:**

**Availability Zone → Datacenter failure**

**Multiple Azure Regions → Region failure**
