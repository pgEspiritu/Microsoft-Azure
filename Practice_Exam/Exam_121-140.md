## 121. You need to configure an Azure solution that meets the following requirements:

- Secures websites from attacks.
- Generates reports that contain details of attempted attacks.

What should you include in the solution?

- Azure Firewall.
- A Network Security Group (NSG).
- Microsoft Purview Information Protection.
- DDoS protection.

**Answer:** DDoS protection.

**Explanation:** **Azure DDoS Protection** helps protect Azure resources, including websites and applications, from **Distributed Denial-of-Service (DDoS) attacks**. It provides monitoring, attack analytics, and reporting information about detected DDoS attacks.

**Why the others are incorrect:**

- **Azure Firewall** — Provides centralized network traffic filtering and application/network rules, but it is not specifically designed to protect websites from DDoS attacks and provide DDoS attack reports.
- **Network Security Group (NSG)** — Controls inbound and outbound network traffic based on IP addresses, ports, and protocols, but does not provide dedicated DDoS protection and attack reporting.
- **Microsoft Purview Information Protection** — Classifies, labels, and protects sensitive information such as documents and emails; it does not protect websites from network attacks.

**Exam tip:**

**Website/application + DDoS attacks + attack reports → Azure DDoS Protection**

- Multiple Microsoft Entra ID directories.
- Multiple regions.
- Multiple resource groups.

**Answer:**
- Multiple subscriptions.
- Multiple resource groups.

**Explanation:** Azure provides several ways to logically separate and manage resources. For different departments, **subscriptions** and **resource groups** are appropriate segmentation mechanisms.

**Why the answers are correct:**

- **Multiple subscriptions** — Each department can have its own subscription, providing a separate management, billing, and access-control boundary. Department administrators can be assigned appropriate permissions within their subscription.

- **Multiple regions** — Regions determine the physical/geographic location of resources and are not primarily used to separate departments or assign administrative boundaries.

**Exam tip:**

**Department/resource organization → Resource Groups**

**Strong management and billing boundary → Subscriptions**

**Why the others are incorrect:**

- **Scalability** — The ability to increase or decrease the capacity of a system to handle workload changes.
- **Low latency** — Refers to minimizing the delay in communication or data processing; it does not provide protection against data center failures.

**Exam tip:**

**Survive component/data center failure → Fault tolerance**

**Automatically adjust resources → Elasticity**

**Handle increasing workload → Scalability**

**Minimize communication delay → Low latency**

Therefore, the answer is **Fault tolerance**.
