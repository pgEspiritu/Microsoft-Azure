## 141. Your company plans to migrate all its data and resources to Azure. The company migration plan states that only Platform as a Service (PaaS) solutions must be used in Azure. You need to deploy an Azure environment that meets the company migration plan. Solution: You create an Azure App Service and Azure virtual machines that have Microsoft SQL Server installed. Does this meet the goal?

- Yes.
- No.

**Answer:** No.

**Explanation:** The solution does not meet the requirement because **Azure Virtual Machines are Infrastructure as a Service (IaaS)**, not PaaS.

Although **Azure App Service** is a PaaS service, the virtual machines running Microsoft SQL Server are still IaaS resources. Therefore, the solution violates the requirement that **only PaaS solutions** must be used.

**Why the answer is No:**

- **Azure App Service** → PaaS
- **Azure Virtual Machines** → IaaS
- **SQL Server installed on an Azure VM** → IaaS

To meet the requirement, the company could use a PaaS database service such as **Azure SQL Database** instead of installing SQL Server on a virtual machine.

**Exam tip:**

**App Service → PaaS**

**Azure SQL Database → PaaS**

**Azure Virtual Machine → IaaS**

Therefore, the solution **does not meet the goal**.

**Answer: No.**

## 142. Your company hosts an accounting application named App1 that is used by all the customers of the company. App1 has low usage during the first three weeks of each month and very high usage during the last week of each month. Which benefit of Azure Cloud Services supports cost management for this type of usage pattern?

- High availability.
- High latency.
- Elasticity.
- Load balancing.

**Answer:** Elasticity.

**Explanation:** **Elasticity** allows cloud resources to automatically **scale up or down based on demand**.

In this scenario, App1 has:

- **Low usage** → During the first three weeks, fewer resources are needed.
- **Very high usage** → During the last week, additional resources can be provisioned.
- **After the peak period** → Resources can be reduced again to avoid unnecessary costs.

This helps the company **pay for the resources it actually needs** rather than maintaining enough infrastructure for the peak workload throughout the entire month.

**Why the others are incorrect:**

- **High availability** — Ensures services remain accessible despite failures; it does not directly address changing workload demand.
- **High latency** — Refers to delays in communication and would be undesirable.
- **Load balancing** — Distributes traffic across resources but does not automatically adjust the amount of resources based on demand.

**Exam tip:**

**Variable workload + automatically increase/decrease resources + cost optimization → Elasticity**
