## 195. You are tasked with deploying a critical LOB application, which will be installed on a virtual machine, to Azure. - No.

**Explanation:** To achieve a **99.99% Azure SLA for virtual machines**, the VMs must be deployed across **two or more Availability Zones** in a region that supports the required SLA.

Deploying **two VMs in only one Availability Zone** does not provide protection against a failure affecting that entire zone.

The VMs need to be distributed across **at least two Availability Zones** so that if one zone becomes unavailable, the application can continue running in the other zone.

**Why the answer is No:**

- **2 VMs + 1 Availability Zone** → A zone-level failure can affect both VMs.
- **2 VMs + 2 Availability Zones** → Provides zone redundancy and can meet the 99.99% VM availability SLA where supported.

**Exam tip:**

**99.99% VM SLA → 2 or more VMs deployed across 2 or more Availability Zones**

**Availability Set** and **Availability Zone** are different concepts:
- **Availability Set** → Protects VMs from hardware/rack-level failures within a datacenter.
- **Availability Zones** → Protects against failures of an entire datacenter/zone within an Azure region.

Therefore, **two VMs in one Availability Zone do not meet the goal**.
