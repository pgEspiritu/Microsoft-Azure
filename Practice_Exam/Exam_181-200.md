## 181. You are tasked with deploying Azure virtual machines for your company. You need to make use of the appropriate cloud deployment solution. Solution: You should make use of Platform as a Service (PaaS). Does the solution meet the goal?

- Yes.
- No.

**Answer:** No.

**Explanation:** **Azure Virtual Machines** are an example of **Infrastructure as a Service (IaaS)**, not Platform as a Service (PaaS).

With IaaS, Azure provides the underlying infrastructure, while you manage the virtual machine, including the operating system and installed applications.

**Why the answer is No:**

- **IaaS → Azure Virtual Machines**
- **PaaS → Azure App Service, Azure SQL Database**
- **SaaS → Microsoft 365 and other complete applications**

**Exam tip:**

**Virtual Machines = IaaS**

**App Service = PaaS**

**Microsoft 365 = SaaS**

Therefore, using **PaaS** does **not** meet the goal.

**Answer: No.**

## 183. Your company has an on-premises network that includes a large number of servers. They would like to make extra resources available to their users, while keeping capital and operational overheads to a minimum. You are required to make recommendations that should be included in the overall solution.

**Solution:** You should endorse the use of an added data center as part of the solution. Does the solution meet the goal?

- Yes.
- No.

**Answer:** No.

**Explanation:** Adding another **on-premises data center** would require significant **capital expenditure (CapEx)** and **operational expenditure (OpEx)** for infrastructure, hardware, facilities, maintenance, power, cooling, and staffing.

The goal is to provide **additional computing resources while minimizing capital and operational overhead**. A **public cloud solution such as Azure** is more appropriate because cloud services use a pay-as-you-go model and reduce the need to purchase and maintain additional physical infrastructure.

**Why the answer is No:**

- **Additional data center** → Requires significant CapEx and ongoing OpEx.
- **Public cloud** → Provides additional resources without requiring the company to build and maintain its own data center.
- **Azure** → Supports on-demand provisioning and pay-as-you-go pricing.

**Exam tip:**

**Minimize CapEx + minimize infrastructure management → Public cloud**

**Build another data center → High CapEx + ongoing OpEx**

Therefore, adding another data center **does not meet the goal**.

**Answer: No.**

## 184. Your company has an on-premises network that includes a large number of servers. They would like to make extra resources available to their users, while keeping capital and operational overheads to a minimum. You are required to make recommendations that should be included in the overall solution.

**Solution:** You should endorse the use of a hybrid cloud as part of the solution. Does the solution meet the goal?

- Yes.
- No.

**Answer:** Yes.

**Explanation:** A **hybrid cloud** combines the company's existing **on-premises infrastructure (private cloud)** with **public cloud resources**, such as Azure.

This allows the company to provide additional computing resources without having to purchase and maintain another physical data center. The organization can use Azure resources when additional capacity is needed while continuing to use its existing on-premises infrastructure.

This can help minimize **capital expenditure (CapEx)** because the company does not need to build additional physical infrastructure to accommodate increased demand.

**Why the answer is Yes:**

- **Existing on-premises infrastructure** can continue to be used.
- **Azure public cloud resources** can provide additional capacity.
- The company avoids the large upfront cost of building another data center.
- Cloud resources can be provisioned as needed.

**Exam tip:**

**Existing on-premises infrastructure + public cloud → Hybrid cloud**

**Need extra resources while minimizing CapEx → Consider public/hybrid cloud**

Therefore, using a **hybrid cloud** meets the goal.

**Answer: Yes.**

## 186. Your company is planning to migrate all their virtual machines to an Azure pay-as-you-go subscription. The virtual machines are currently hosted on Hyper-V hosts in a data center. You are required to make sure that the intended Azure solution uses the correct expenditure model.

**Solution:** You should recommend the use of the elastic expenditure model. Does the solution meet the goal?

- Yes.
- No.

**Answer:** No.

**Explanation:** Azure uses **Capital Expenditure (CapEx)** and **Operational Expenditure (OpEx)** models, not an "elastic expenditure model."

A **pay-as-you-go Azure subscription** follows an **Operational Expenditure (OpEx)** model because the company pays for cloud resources based on their usage rather than purchasing physical infrastructure upfront.

**Why the answer is No:**

- **OpEx** → Pay for resources as they are consumed; typical of cloud services.
- **CapEx** → Large upfront investment in physical infrastructure such as servers and data centers.
- **Elasticity** → A cloud characteristic that allows resources to scale up or down based on demand; it is not an expenditure model.

**Exam tip:**

**Pay-as-you-go → OpEx**

**Buying physical servers/data centers → CapEx**

**Automatically scaling resources → Elasticity**

Therefore, recommending an **elastic expenditure model** does **not** meet the goal.

**Answer: No.**
